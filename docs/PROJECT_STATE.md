## 1. Что за проект
Интернет-магазин техники LOW-Market (экс-«ВОЛЬТ»). Розница Москва/МО, компьютерная
техника — ядро ассортимента. Субдистрибьютор, кроссдокинг, 6000 SKU через API
поставщика. ИП УСН. Разработка: владелец + Claude, Windows/VSCode/GitHub/Yandex Cloud.

## 4. Ключевые решения (не пересматривать без причины)
- Кастомный стек вместо Битрикс (решение принято, обсуждено).
- Матрица наценок по категориям (8–45%), floor-контроль, цены на …90 — src/lib/pricing.ts.
- Защищённые поля товара при синке: description, images.
- Пропавшие из фида товары деактивируются, не удаляются.
- Разделение баз: локальная (разработка) и серверная (прод) — не смешивать.
- Налоги: закладывать НДС (порог УСН 20 млн будет превышен), ставка 22% с вычетом
  вероятно выгоднее 5-7% — на согласовании с бухгалтером.
- Названия/бренд: LOW-Market.
