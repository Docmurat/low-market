# LOW-Market — платформа интернет-магазина техники

Кастомная e-commerce платформа: розница + опт, кроссдокинг со склада поставщика,
6000 SKU через API, доставка по Москве и МО.

## Стек

- **TypeScript + Next.js 14** (App Router, SSR для SEO) — фронт и API в одном проекте
- **PostgreSQL + Prisma** — данные
- **Tailwind CSS** — стили
- Позже: Redis (кэш), ЮKassa (карты+СБП+чеки 54-ФЗ), Yandex Object Storage (фото)

## Запуск локально (Windows, VSCode)

Требуется: Node.js 20+, PostgreSQL 17 (у нас — на порту **5433**; порт 5432 занят
посторонним PostgreSQL 14, его не трогаем). Docker не используется.

```bash
# 1. Зависимости
npm install

# 2. Переменные окружения: скопировать .env.example в .env,
#    вписать пароль postgres и порт 5433 в DATABASE_URL
copy .env.example .env

# 3. Миграция схемы БД (создаст таблицы в базе voltshop)
npx prisma migrate dev

# 4. Категории + демо-товары (через пайплайн синхронизации)
npm run seed

# 5. Запуск
npm run dev
# -> http://localhost:3000
```

Полезное: `npx prisma studio` — GUI для просмотра БД; `npm run sync` — повторная
синхронизация с (пока мок-) API поставщика.

## Архитектура ценообразования (важно!)

`src/lib/pricing.ts` — матрица наценок по категориям (видеокарты 8% … кабели 45%),
floor-контроль (закупка + эквайринг 2% + буфер 3%) и «красивое» окончание цены на 90.
Розничная цена пересчитывается при каждой синхронизации. Переопределить наценку
конкретной категории можно полем `markupPct` в БД — оно сильнее матрицы.

`scripts/sync-supplier.ts` — единый пайплайн загрузки товаров. Сейчас читает
`data/supplier-mock.json`, на шаге 6 переключим на реальный API (контракт данных
уже зафиксирован типом `SupplierItem`). Правила: upsert по артикулу поставщика,
пропавшие из фида товары деактивируются (не удаляются), наши описания и фото
при обновлении НЕ затираются.

`src/lib/site.ts` — название сайта, URL и описание (единая точка правды о бренде).

## Структура

```
prisma/schema.prisma        — модели Category, Product
prisma/seed.ts              — дерево категорий + демо-товары
scripts/sync-supplier.ts    — синхронизация с поставщиком (ядро дропшипа)
data/supplier-mock.json     — имитация ответа API поставщика
src/lib/pricing.ts          — матрица наценок, floor, округление
src/lib/site.ts             — бренд: название, URL, описание
src/app/page.tsx            — главная
src/app/catalog/[slug]/     — страница категории
src/app/product/[slug]/     — карточка товара
src/components/             — Header, Footer, ProductCard
```
